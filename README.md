# Car Price Prediction

## Introduction
This project predicts the selling price of used cars using Machine Learning.

## Dataset
CarDekho Car Price Dataset

## Model Used
Random Forest Regressor

## Features
- Present Price
- Kms Driven
- Fuel Type
- Seller Type
- Transmission
- Owner
- Car Age

## Evaluation Metrics
- RMSE
- R2 Score

## Results
The model achieved good accuracy in predicting car prices.
